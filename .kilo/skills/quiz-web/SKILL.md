# Quiz Web Skill

Hãy đặt nội dung skill riêng của project này bên dưới phần này.

## Cấu trúc project

- `index.html`: giao diện chính.
- `app.js`: logic ứng dụng, luồng làm bài và thông báo.
- `supabase.js`: kết nối dữ liệu cloud.
- `style.css`: giao diện và responsive.
- Các file `*_questions.js`: dữ liệu câu hỏi theo môn.

## Quy tắc mặc định

- Giữ nguyên giao diện và nội dung tiếng Việt hiện có.
- Không xóa hoặc thay đổi dữ liệu câu hỏi nếu không được yêu cầu.
- Khi sửa logic thông báo, kiểm tra cả `app.js` và `supabase.js`.
- Ưu tiên thay đổi nhỏ, tương thích với code hiện tại.
- Sau khi sửa JavaScript, chạy `node --check app.js` và `node --check supabase.js`.
